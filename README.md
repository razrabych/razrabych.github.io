# Разрабыч — демо-проекты сайтов

Статический сайт-витрина, на котором собраны демо-макеты сайтов для бизнеса:
лендинги и многостраничные сайты для разных сфер — от салона красоты до
строительной компании.

Собран на чистом **HTML + CSS (SCSS) + JavaScript**, без фреймворков и сборки
на стороне сервера.

## Быстрый старт

```bash
npm install     # один раз
npm run build   # скомпилировать SCSS → css/style.css
npm run watch   # пересобирать стили автоматически при правках SCSS
```

После `npm run build` просто откройте `index.html` в браузере — сайт работает
без сервера и без дополнительной сборки (все стили и скрипты подключены
относительными путями).

## Как добавить или изменить проект

Все проекты — в файле **`projects/projects.js`**, в массиве `PROJECTS`.
Чтобы добавить новый, скопируйте объект и заполните поля:

```js
{
  slug: 'my-project',          // уникальный id (латиницей, без пробелов)
  title: 'Название проекта',
  type: 'Лендинг',             // Лендинг / Сайт для бизнеса
  summary: 'Короткое описание для карточки.',
  demo: 'demos/my-project/',   // ссылка на демо (или внешний URL, или "#")
  image: 'projects/x/img.png', // (необязательно) скриншот-превью вместо мокапа
  accent: '#E89BB4',           // акцентный цвет мокапа
  accentDark: '#3A2028',       // тёмный цвет мокапа
}
```

### Превью карточки

- Если задано поле `image` — показывается картинка (с сохранением пропорций).
- Если `image` нет — рисуется схематичный мокап браузера в цветах `accent` / `accentDark`.
